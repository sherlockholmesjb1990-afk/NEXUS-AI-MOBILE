# NEXUS V1.31 — Validation

## Objetivo
Adicionar um harness determinístico sem I/O Android para proteger o contrato de evidência/verificação e preparar regressão automática no CI.

## Alterações
- versionCode 39 / versionName 1.31
- `NexusRegressionHarness` com 5 casos determinísticos
- teste JUnit do harness
- botão `🧪 Regressão` na UI para executar somente o harness local
- CI já executa `gradle test` antes do APK

## Casos
1. Clipboard com evidência independente correspondente → CONFIRMED
2. Clipboard divergente → FAILED
3. Evidência ausente → UNKNOWN
4. Evidência stale (>30s) → UNKNOWN
5. Fonte de evidência irrelevante → UNKNOWN

## Segurança
O harness não executa ferramentas, não solicita permissões, não acessa clipboard, câmera, rede ou serviços Android.

## Validação deste pacote
A validação estrutural deve ser feita antes do commit. O build Android final continua sendo responsabilidade do GitHub Actions/Android Studio.
