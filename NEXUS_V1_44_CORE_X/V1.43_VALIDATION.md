# V1.43 VALIDATION — Cycle Resume Isolation

## Objetivo
Eliminar a dependência do único checkpoint em `tasks` para retomadas quando o mesmo `taskId` possui ciclos de execução independentes.

## Alterações
- Banco sobe de schema 19 para 20.
- Criada `cycle_resume_anchors` com chave primária composta `(task_id, cycle_id)`.
- `AgentJournal.checkpoint(...)` persiste o anchor por ciclo quando `cycleId` está presente.
- `AgentJournal.cycleResumeAnchor(...)` recupera exclusivamente por `taskId + cycleId`.
- `NexusAgent` usa o anchor por ciclo e mantém fallback para dados anteriores à V1.43.
- Teste A/B ampliado para verificar isolamento e coexistência conceitual de anchors A/B.
