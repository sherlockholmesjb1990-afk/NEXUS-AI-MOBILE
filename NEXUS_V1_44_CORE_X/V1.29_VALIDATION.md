# NEXUS V1.29 — Validation

## Changes validated statically
- versionCode 37 / versionName 1.29.
- MainActivity no longer creates a fresh NexusVisionCapture for the capture button.
- CameraX capture uses OutputFileOptions and a temporary cache JPEG.
- Android evidence abstraction is read-only and provenance-aware.
- Clipboard write requires independent read-back evidence for CONFIRMED.
- UNKNOWN is preserved when evidence is missing or insufficient.
- MultiStepExecution records evidence collection before verification.

## Build limitation
This workspace does not expose a usable Gradle Wrapper/Android build environment, so no local APK build was claimed. CI/Android Studio must perform the final compile/runtime validation.

## Device test checklist
1. Open V1.29.
2. Tap camera.
3. Grant camera permission.
4. Wait for “Câmera pronta para captura.”
5. Capture a photo; verify preview closes and image is attached for analysis.
6. Send a simple message with the captured image.
7. Exercise `clipboard_write` only through an authorized task; verify Journal contains ACTION_EVIDENCE_COLLECTED and a CONFIRMED result only when independent clipboard read-back matches.
