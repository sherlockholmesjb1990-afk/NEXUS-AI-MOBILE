# NEXUS V1.35 — Validação CI / Build

## Objetivo
Transformar o checkpoint V1.34 em uma etapa reproduzível de CI, eliminando a referência a um diretório legado inexistente e preparando a geração verificável do APK Debug.

## Alterações
- `app/build.gradle.kts`: versionCode 43 / versionName 1.35.
- `MainActivity.kt`: identidade visual atualizada para V1.35.
- `.github/workflows/android.yml`: `test` e `assembleDebug` passam a executar na raiz real do projeto.
- Artefato do APK passa a ser coletado de `app/build/outputs/apk/debug/*.apk`.
- Workflow usa Gradle 8.9, Java 17 e Android SDK 35.
- Logs de `test` e `assembleDebug` usam `--stacktrace` para diagnóstico objetivo de falhas.
